Verso 会更新 package manifest，生成 Angular 风格的 conventional changelog，创建 release commit
和 tag，最后以原子操作推送当前上游分支和 release tag。

```sh
pnpm add -D @amamo/verso
```

## 刻意保持边界清晰

Verso 面向所有 JavaScript 软件包共用同一版本号的仓库。它负责版本文件、changelog、commit、tag
和原子推送这一段发布边界，不接管软件包发布、CI 编排或项目自己的构建步骤。

| 阶段 | Verso 负责                                                     | 项目负责                   |
| ---- | -------------------------------------------------------------- | -------------------------- |
| 检查 | 校验配置、软件包版本、Git 状态和上游分支                       | 通过钩子运行项目自己的检查 |
| 准备 | 更新 manifest 和配置的 Cargo 文件；在 changelog 顶部写入新版本 | 按配置执行构建或测试       |
| 记录 | 创建 release commit 和准确的版本 tag                           | 在 CI 中发布软件包         |
| 推送 | 原子推送当前上游分支和 tag                                     | 响应新推送的 tag           |

## 安全优先

- `verso --dry-run` 只生成发布计划，不写文件，也不执行会修改状态的 Git 命令。
- 本地步骤失败时会回滚发布文件，并取消 Verso 自己的暂存内容。
- 分支和 tag 通过 `git push --atomic` 一起推送。
- 推送失败时保留本地 commit 和 tag，避免隐藏已经完成的工作。
